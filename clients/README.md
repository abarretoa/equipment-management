# Client profiles

Each directory here is one organisation's identity for the product: names,
logos, colours, Responsibility Term content and business values. A build
embeds exactly one of them; a deployment serves exactly one organisation.

- `default/` — the neutral demonstration profile (fictional "Acme
  Consulting"). Its term wording is illustrative and not legally reviewed.

Selection, file formats, validation and how to add a profile:
[docs/WHITE_LABEL.md](../docs/WHITE_LABEL.md).
